# PII Guard interface

Operate mode. Preserve the user-approved chat theme rather than the old review dashboard presentation. Use black, white and neutral gray, SF Pro throughout (native macOS system face), with no monospace styles, a quiet full-height sidebar, generous conversation space and a compact rounded composer. The rounded diamond-loop mark is shared across employee and manager views. Use simple SVG controls for navigation/add/send with accessible names.

Headings are generous: 40–42px desktop and 32–34px mobile, with 22–24px section titles. Body text stays near 15px. Controls have at least 44px targets. Light/dark/system appearance persists without storing credentials. Motion is restrained spring easing on controls/drawers; respect reduced motion. A small Strands loader accompanies processing.

Sent originals align right and sanitized replies align left. File cards have one clean surface, thumbnails, and clickable previews. Downloads stay available while manager review is pending and during manager outages; an explicit denial blocks them. Display incomplete local review as a warning. Preserve charts, diagrams, visual crops and source maps in a focused Details view with concise labels, rather than an explanatory dashboard covering the chat. Existing review controls remain available without changing engine decisions.

The manager shows a mobile-friendly filename/time list, then affected original parts versus replacements and Approve/Deny controls. No authentication, metric-card wall, policy/version exposition or unrelated navigation. Engine readiness and approval states remain distinguishable.
