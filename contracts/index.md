# contracts

Generated backend OpenAPI contract shared with the frontend; export using scripts/export-api-schema.sh when implemented.

This is a file plan. **Existing** files are present; **Planned** files must be implemented in the owning issue. This documentation does not create application code.

## Files

| Filename | Status | Responsibility |
|---|---|---|
| `index.md` | Existing | Directory file manifest and responsibilities; keep it synchronized with changes. |
| `openapi.json` | Planned | Generated backend API specification. |
| `engine.schema.json` | Planned | Engine input/output contract snapshot. |
| `integration.schema.json` | Planned | Session, policy, reporting event, and provider adapter contracts. |

Generated caches, dependencies, runtime uploads, and `.git/` are excluded from directory manifests.
